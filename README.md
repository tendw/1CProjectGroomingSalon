# 🐾 Конфигурация «ГрумингСалон»

Учебный проект самописной конфигурации на платформе **1С:Предприятие 8.3**, разработанный в рамках прохождения курса **«Разработчик 1С» от Яндекс Практикума**.

Проект предназначен для автоматизации основных бизнес-процессов салона по уходу за домашними животными (запись клиентов, проведение процедур, учет материалов и взаиморасчеты).

---

## 🛠 Технологический стек

* **Платформа:** 1С:Предприятие 8.3 (версия 8.3.21+)
* **Среда разработки:** 1С:EDT (1C:Enterprise Development Tools)
* **Система контроля версий:** Git + GitHub
* **Библиотека стандартных подсистем (БСП):** Интегрированы базовые подсистемы для работы с пользователями, версионированием и сервисными функциями.

---

## 🚀 Основной функционал

### 1. Учёт клиентов и питомцев
* Ведение справочника владельцев и карточек питомцев (порода, возраст, особенности ухода).
* История посещений и проведенных процедур для каждого животного.

### 2. Управление услугами и записью
* Запись на стрижку, экспресс-линьку, мытье и гигиенические процедуры.
* Планирование графика работы мастеров-грумеров.

### 3. Учет материалов и продажа сопутствующих товаров
* Списание расходных материалов (шампуни, бальзамы) при оказании услуг.
* Учет остатков товаров на складе и продажи в розницу (корма, аксессуары).

### 4. Взаиморасчеты и аналитика
* Фиксация оплаты услуг клиентов.
* Отчеты по выручке, популярности услуг и загрузке мастеров.
